## 핵심 수정
이전 네 장은 사용자가 거절한 방향이다. 단순히 저채도·저대비·부드러운 천국으로 해석하면 안 된다. 핵심은 1990년대 말~2000년대 초 종교 전단/홈페이지의 촌스러운 포토샵 합성이다. Background.png의 선명한 파란 하늘도 가능하다. 하얗게 터지는 빛, 길게 뻗는 방사형 광선, 흐리게 확대된 사진 조각, 반복 구름 도장, 과한 렌즈 플레어, 어색한 마스킹과 서로 다른 크기의 피사체를 조합한다. 전체가 균일하게 매끈하거나 뽀얀 것만으로는 부족하다.

금빛 보석과 보라/분홍 판타지 일러스트로 돌아가지 않는다. 원본 레퍼런스의 배치까지 복제하지 않고 이미지마다 중심 위치·밀도·비율·피사체 크기를 바꾼다. 예수님을 그릴 경우 얼굴만 모자이크한다. 이번 v2에는 예수님이 없다.

이전 파일은 비교 및 기존 참조 보존을 위해 유지했다. v2는 리소스 파일이며 게임 화면의 자동 교체는 하지 않았다.
