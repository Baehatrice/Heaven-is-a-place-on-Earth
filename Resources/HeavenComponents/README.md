# Heaven Components

총 72개 PNG: icons 기존 승인 아이콘 24종, office-icons 추가 업무/웹 아이콘 24종, web-badges 버튼/배지/배너 24종.
index.html에서 밝은/어두운 배경으로 미리보기. manifest.json에 경로, 크기, 투명도 기록.
아이콘은 투명 PNG. 사각 배너는 자체 배경 포함. 기존 시트는 개별 셀로 분리했습니다.
components.css와 editable-components.html은 문구·색상 수정 가능한 버튼 원본입니다.

사용: <img src="Resources/HeavenComponents/icons/mailbox.png" width="48" alt="메일함">
비율 유지, image-rendering:pixelated 권장. 실제 기능은 button/a와 게임 코드로 연결합니다.

스타일: 90년대 개인 홈페이지, Windows95/WinFiles, 작은 광고 배너. 픽셀 윤곽, 디더링, 회색 입체 테두리, Times/Courier. 이 아이콘의 금색/고채도를 천국 배경 전체의 판타지 화풍으로 확대 해석하지 않습니다.

추가 아이콘 제작: 내장 이미지 생성 도구. 프롬프트 요약: 6열×4행 투명 시트, 90년대 Windows95/shareware clipart, 32~48픽셀 확대 느낌, 디더링·작은 입체 하이라이트, 주소록·메일·검색·프린터·컴퓨터·달력·방명록 등 24종, 글자 없음. PNG 분리는 원본 시트 추출. 버튼 PNG는 HTML/CSS 브라우저 렌더링.
