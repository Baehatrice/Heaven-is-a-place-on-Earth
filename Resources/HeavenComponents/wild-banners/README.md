# Wild Banners / 제각각인 옛 웹 광고 30종

index.html: 실제 크기가 서로 다른 PNG를 모은 미리보기. 클릭하면 개별 저장.
editable.html + banners.css: 글자·크기·색·기울기·늘림을 수정하는 원본.
manifest.json: 각 PNG 크기와 HTML 마크업.

## 조사한 스타일
Early Web Vernacular / GeoCities personal web / 88×31 web badges.
참고: https://hellnet.work/8831/ (GeoCities 배지 아카이브), https://stylogeny.com/styles/early-web/ (스타일 개요).
이 묶음은 여기에 WordArt, 크롬 글자, 신문 제호, 손글씨, 도장, 경고 테이프, 세로 광고를 섞은 독자적인 게임용 그래픽이다. 하나의 통일된 Y2K 스타일로 취급하지 않는다.

## 핵심
통일하지 않는 것이 규칙. 각 배너가 다른 사이트/다른 제작자에게서 온 듯 보여야 한다. 88×31, 468×60, 100×220 등 실제 크기로 섞는다. 동일한 카드 틀에 맞추거나 같은 글꼴·버튼 비율로 정규화하지 않는다. 폰트·굵기·늘림·자간·음영·테두리·색·정보 밀도를 개별 지정한다.

PNG는 현재 컴퓨터에서 렌더링한 확정본. HTML은 설치된 글꼴에 따라 모양이 달라질 수 있다. 폰트 파일을 재배포하지 않는다. 버튼 기능은 실제 사용 시 연결한다.
