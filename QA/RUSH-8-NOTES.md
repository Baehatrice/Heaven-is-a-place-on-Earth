# rush-qa-8

- 성공마다 별 입자와 팝업 숫자를 확대했다. 자동 발송의 큰 숫자 연출은 0.7초 간격으로 제한하고 동시에 3개까지만 유지한다. 클릭을 막지 않는다.
- 러시 중 0.13초 간격으로 새로 작성한 16음 8비트 멜로디/베이스/타격음을 재생한다. 기존 게임 음원을 사용하지 않는다. QA 정지와 비활성 탭에서는 진행이 정지하고 기존 효과음 출력 제어를 따른다.
- 작업 시간 35초마다 6초 동안 움직이는 은총 보너스 버튼이 나타난다. 클릭하면 8초간 2배, 세 번째 기회마다 3배. 피버와 곱으로 중첩한다. 실적은 그대로이고 은총만 증폭한다. 스킬창/수련/수동 탐색 중에는 새 기회를 생성하지 않는다. QA에 등장/획득/도주 및 배율을 남긴다.
- 대리 천사는 음수 내부 수신인 ID를 발급하는 독립 전용 명단을 사용한다. 수동 주소록/선택/작성 중 주소를 전혀 소비하지 않는다. 내 명단 보충 중에도 자동 작업은 계속되지만 수련 중에는 기존 규칙대로 멈춘다.
- 천사 1/2/3단계에 따라 하단 상태창 1/2/3개를 표시한다. 전체 자동 발송 주기는 기존 5/2.5/1초, 표시 창은 순환 사용한다. 전도 대각성의 다중·메아리 적용은 유지한다.
- 넓어진 시야도 아래 132px 천사 구역을 침범하지 않는다. 천사 미습득 시에는 하단 배경 공간으로 남는다.

검증: browser-rush8.cjs에서 독립 명단 보존, 실제 2배 지급, 3개 창 배치, 보너스 획득/도주, QA 정지, 수동 탐색 중 자동 발송, 러시 실행, 화면 오류 없음 확인. 기존 199개 검증과 QA 내보내기, 발송/재시도/중복 정산, 배타 경로 관련 회귀 테스트 통과. 화면은 1440×900 Chrome에서 확인. 음악은 Web Audio로 합성되며 실제 체감 음량/곡의 취향은 다음 플레이에서 확인할 부분이다.

독립 명단으로 자동화의 생산 한계가 달라졌으므로 이전 버전의 점수 분포와 직접 비교하지 않는다. 기존 가격을 유지했으며 이번 변경으로 전체 경제 균형이 확정되었다는 의미는 아니다. 다음 사람 QA에서는 자동화의 수동 대비 점유율과 이동 보너스 획득 비율을 확인한다.
